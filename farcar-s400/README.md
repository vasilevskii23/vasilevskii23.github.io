# Темы FarCar S400

Тёмные темы для мультимедиа **FarCar S400** (UIS7862 / FYT53, экран **1280×720**) в стиле популярных платных скинов CarWebGuru (Dashboard DX, Captain, Offroad, Alien).

## Темы

| Тема | Стиль |
|------|--------|
| **Pajero 4** | оффроуд, янтарь, ночная трасса |
| **Мстители** | тёмный героический, алый / синий |
| **Веном** | чёрный глянец, симбиот |
| **Ганстерленд** | нуар, золото, арт-деко |
| **Чёрный Дракон** | лак, багровый дракон |

## Что внутри каждой темы

Функции как у топовых дашборд-тем:

- левый мультивиджет: спидометр / компас / ярлыки  
- правый мультивиджет: музыка / аналоговые часы / ярлыки  
- подсказки навигатора, дорога + машинка, статистика поездки  
- док ярлыков (нави, радио, музыка, BT, приложения, настройки)  
- яркость, таймер отдыха, GPS (если доступен)

Пакет ZIP также содержит:

- `wallpaper.jpg` — обои 1280×720  
- `CarWebGuru/cfg/` — лого и `car_move.png` / `car_stop.png`  
- `boot/logo.bmp` + `boot/bootanimation.zip` — заставка FYT

## Установка

### Вариант A — CarWebGuru

1. Установите CarWebGuru на магнитолу.  
2. Скачайте ZIP нужной темы из [галереи](./index.html).  
3. Скопируйте файлы из `CarWebGuru/cfg` в папку CWG на устройстве (CWG → О программе → Папки).  
4. Tools → Background → поставьте `wallpaper.jpg`.

### Вариант B — Boot logo (FYT / UIS7862)

На USB:

- `logo.bmp`
- `bootanimation.zip`
- `lsec6315update`

Вставьте USB → подтвердите обновление.

### Вариант C — Веб-дашборд

Откройте `index.html` в Chrome на весь экран. Выбор домашнего лаунчера на FarCar: код **8086**.

## Генерация заново

python3 farcar-s400/scripts/generate_assets.py
