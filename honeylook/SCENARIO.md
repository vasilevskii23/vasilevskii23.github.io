# МЕДООК (HONEYLOOK)

Короткий бездиалоговый шорт в духе корейских «Тюленьков» (SEALOOK): мягкий слэпстик, мимика, звуки «клик/хмпф», ~90 секунд, 0+.

## Персонажи

- **Медоед №07** — круглый, упрямый, с номерной биркой на боку (как метки у тюленей).
- **Пчёлка** — маленький круглый шарик, не страшная, скорее сосед по приключению.

## Серия 1: «Капля»

| Время | Что на экране |
|------:|---------------|
| 0–3 с | Карточка: **МЕДООК** · тихий «документальный» вайб |
| 3–10 с | Медоед дремлет на песке. Нюхает воздух. Уши дёрнулись. |
| 10–22 с | Увидел соты. Подкрадывается: преувеличенный «стелс» на коротких лапах |
| 22–35 с | Тыкает носом → мёд шлёп на морду. Лижет. Счастье. |
| 35–48 с | Появляется пчёлка. Долгий взгляд глаз в глаз. |
| 48–68 с | Оба кидаются к мёду → сталкиваются → мёд фонтаном → оба липкие |
| 68–82 с | Делят одну каплю. Кивают друг другу. |
| 82–90 с | Финал-карточка: бирка **07** и надпись «конец… пока» |

## Правила стиля (как у «Тюленьков»)

- Без реплик — только звуки и мимика
- Один простой гэг на серию
- Пастель, круглые формы, никаких страшных пчёл/зубов
- Юмор добрый: упрямство + неловкость, не злость
