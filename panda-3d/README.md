# Lifotronic Panda — 3D

Интерактивная 3D-модель плюшевой панды в красном худи **Lifotronic**, собранная по фотореференсам.

## Открыть

Откройте [`index.html`](./index.html) через локальный сервер (модули ES требуют HTTP):

```bash
cd panda-3d && python3 -m http.server 8765
```

Затем перейдите на http://localhost:8765

## Управление

- **ЛКМ** — вращение
- **Колесо** — зум
- **ПКМ** — панорама
- **Автоповорот** — медленное вращение модели
- **Мех** — показать/скрыть оболочечный плюш
- **Скачать GLB** — экспорт модели для Blender / Unity / т.п.
- Миниатюры внизу — камера под углом соответствующего фото

## Состав модели

- Голова, уши, чёрные патчи глаз, блестящие глазки, коричневый нос
- Красное худи с текстурой и надписью *Lifotronic*
- Шнурки с кисточками, рукава, низ худи
- Короткие чёрные лапки с коричневыми подушечками
- Сидячая поза, лёгкая анимация «дыхания»
- Оболочечный + волокнистый плюш (переключатель «Мех»)
