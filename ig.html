Команда для iPhone · автосохранение в Фото

Один раз собери ярлык — дальше: Instagram → Поделиться → IG Скачать. Или Siri: «IG Скачать».

1

Новая команда

Открой приложение «Команды» → + → имя IG Скачать.

2

Меню «Поделиться»

Кнопка ⓘ → «Показывать в меню Поделиться» → типы: URL и Текст.

3

«Получить содержимое URL»

URL: https://api.pulldl.com/api/shortcut/resolve
Ещё → Метод: POST → Тело: JSON → поле url = переменная Содержимое команды.

4

Достань ссылки на файлы

«Получить значение словаря» → ключ media_urls из ответа предыдущего шага.

5

Скачай и сохрани

«Повторить с каждым» по этому списку → внутри: «Получить содержимое URL» (элемент повтора) → «Сохранить в альбом Фото».

Если API временно не отвечает — пользуйся формой выше: она откроет веб-загрузчик с твоей ссылкой. Запасной шаблон URL: https://pulldl.com/?url= + содержимое команды.

На экран «Домой»: Safari → кнопка «Поделиться» → «На экран Домой» → назови «IG Скачать». Откроется эта страница как мини-приложение.

Скачивай только свои ролики или контент, на который у тебя есть право. Чужие видео защищены авторским правом — не выкладывай их как свои и не используй коммерчески без разрешения автора.
