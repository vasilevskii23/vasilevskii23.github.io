## Система Ричсона — адаптация под сброс веса

Файл: [`Alan_Ritchson_Sistema_Trenirovok.pdf`](./Alan_Ritchson_Sistema_Trenirovok.pdf)

Что внутри:

- цель — **сброс веса**, лимит **≤ 2500 ккал/день**
- меню с макросами и правилом 80/20
- **витамины и спортпит, доступные в РФ** (аптеки + Maxler/ON/Эвалар/Солгар и др.)
- bro-split Пн–Пт + AMRAP в субботу
- **подробный разбор техники** каждого упражнения (исходное положение, шаги, ошибки, советы)
