# Руководства

## Система тренировок Алана Ричсона (Reacher)

Файл: [`Alan_Ritchson_Sistema_Trenirovok.pdf`](./Alan_Ritchson_Sistema_Trenirovok.pdf)

Подробный справочник на русском:

- принципы и статистика
- bro-split Пн–Пт (грудь / спина / ноги / плечи / руки)
- калистеника-база и AMRAP 30 мин
- диета ~4000–4500 ккал, белок 240–300 г, 80/20
- спортпит и витамины (trace minerals, электролиты, methylcobalamin B12, протеин)
- TRT (только как контекст интервью — не инструкция)
- распорядок дня и адаптация под себя

Пересборка PDF:

```bash
python3 guides/generate_ritchson_pdf.py
```
